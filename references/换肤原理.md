# 换肤原理

想加皮肤、改皮肤体系、或者把换肤能力挪到别的页面上，看这一篇就够。

## 一句话原理

**页面里没有任何一处写死颜色。** 所有颜色、圆角都是 CSS 变量；
换皮肤 = 用 JS 把 `document.documentElement` 上的一批变量改掉。改完立刻生效，不用重载。

## 变量表

用的是 Tailwind / shadcn 那套约定，共 8 个基础色 + 1 个圆角：

| 变量 | 作用 |
|---|---|
| `--background` | 页面底色 |
| `--foreground` | 正文颜色 |
| `--card` | 卡片底色 |
| `--primary` | 主色（按钮、选中态、强调） |
| `--primary-foreground` | 主色上的文字色 |
| `--secondary` | 次级底色（输入框、图标底） |
| `--accent` | 淡强调底色（悬停、选中背景） |
| `--border` | 边框 |
| `--radius` | 圆角基准值 |

其余变量（`--muted`、`--ring`、`--radius-sm/md/lg/xl/2xl` 等）**都由这 9 个派生**，
所以定义一套新皮肤只需要给 9 个值 —— 这是整套体系能用起来的关键，
少一个颜色也不会出现某块区域没被染上的情况。

## 派生规则

在 `theme-engine.js` 的 `derive()` 里：

```
--card-foreground  = --foreground
--muted            = --secondary
--muted-foreground = color-mix(in srgb, foreground 52%, background)   ← 自动算出中间灰
--accent-foreground= --primary
--input            = --border
--ring             = --primary
--radius-sm        = radius × 0.375
--radius-md        = radius × 0.5
--radius-lg        = radius × 0.75
--radius-2xl       = radius × 1.25
```

`muted-foreground` 用 `color-mix` 而不是写死灰色，好处是：**深色皮肤下副文字自动变亮，
浅色皮肤下自动变暗**，不需要为每套皮肤分别调对比度。

## 一套皮肤长什么样

```js
{
  id: 'my-skin',
  name: '我的皮肤',
  tag: '一句话感觉',
  brutal: 0,                    // 1 = 启用硬边框硬阴影（neo-brutalism 用的）
  light: { bg, fg, card, primary, primaryFg, secondary, accent, border, radius },
  dark:  { ... 同上一套键 ... }
}
```

`bg` / `fg` / `primaryFg` 是书写时的简写，`derive()` 会认。
写完整变量名（`background` / `foreground` / `primary-foreground`）也认，
两种混用也行 —— 导入外部主题时就是靠这个兼容面。

## 加一套内置皮肤

在 `assets/theme-engine.js` 顶部的 `BUILTIN` 数组里加一项，`light` / `dark` 各给 9 个值即可。
不需要动 CSS，也不需要动渲染逻辑 —— 皮肤面板会自动多出一张卡片，
预览小样（三颗色点 + 一条色条）也是从这 9 个值里自动画的。

## 深浅色是怎么切的

三档：`light` / `dark` / `auto`。

- `light` / `dark`：强制
- `auto`：读 `prefers-color-scheme`，并且**监听系统变化实时跟随**（`matchMedia` 的 change 事件）

`apply()` 里会同时给 `<html>` 打上 `dark` 类名和 `data-mode` 属性，
万一以后有组件需要靠类名取色也能对上。

## 导入安全消毒

外部粘进来的主题**不可信**，必须过三道闸：

1. **键名白名单** —— 只有 `ALLOWED_KEY` 里列出的 CSS 变量名能过，`position`、`content` 之类一律丢弃。
2. **值字符白名单** —— `SAFE_VALUE` 只放行 `a-zA-Z0-9#%.,()/ '*-`，且长度 ≤ 80。
3. **危险模式二次拦截** —— 显式拒绝 `url(`、`expression`、`javascript:`、`@import`、`;`、反斜杠。

为什么要第 3 道：第 2 道的字符集里 `(` `)` `:` 都在白名单内（颜色函数要用），
单靠它挡不住 `url(http://evil/x.png)` 这种。所以必须再加一层模式匹配。
**分号必须拒** —— 分号是 CSS 声明分隔符，放进去就能拿一个变量名注入任意后续声明。

拦下来的数量会累计到 `dropped` 字段，界面上提示「已拦下 N 个非法值」。
如果一个有效值都没有，直接判定为非法主题并拒绝。

## 回退机制

每次换皮肤前把当前状态（皮肤 ID + 自定义 JSON）压进 `lastTheme` 快照，
「回退上一套」就是读这个快照恢复。只有一层，不做无限历史 —— 够用且不会撑爆 localStorage。

## localStorage 键位

| 键 | 存的什么 |
|---|---|
| `yemo_bm_theme` | 当前皮肤 ID |
| `yemo_bm_mode` | `light` / `dark` / `auto` |
| `yemo_bm_custom` | 自定义皮肤 JSON |
| `yemo_bm_last` | 上一套快照 |
| `yemo_bm_view` | `card` / `app` |

全部读写都包了 try/catch —— 隐私模式下 localStorage 会抛异常，不能让它把整个页面带崩。

## 想做到极致可以怎么改

- **按分类着色**：`--cat-color` 已经是每张卡独立的变量（卡片左侧色条、分类标签用它），
  想改成「分类颜色跟着皮肤主色走」，在 `catColor()` 里用 `color-mix` 派生色相即可。
- **加毛玻璃**：顶栏已经是 `backdrop-filter: blur()`，把 `--card` 换成半透明值就有玻璃感。
- **字体也换肤**：`--font-sans` 已经在变量表里，皮肤里加 `"font-sans": "'某字体', sans-serif"` 就能连字体一起换。
